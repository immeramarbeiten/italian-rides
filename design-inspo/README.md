# Design inspo — drop screenshots here

How this works:

1. **You:** drop 5–15 screenshots in this folder — anything that feels right
   (Apple, Airbnb, Stripe, or favorites I wouldn't guess). Any format (PNG/JPG/WebP).
2. **Optional:** add a line per image in `notes.md` saying *what* you like about it
   (e.g. "the table density", "the calm hero", "this exact blue").
3. **Tell me** when the folder is ready.
4. **I** build 2–3 coded direction examples with real ScooterParts content for you to vote on.
5. Winner gets tokenized (type, color, spacing, motion) → then we rebuild.

No rules beyond that — more is better than curated.
