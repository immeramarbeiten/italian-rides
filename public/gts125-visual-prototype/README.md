# GTS 125 reference visualization prototype

Open `index.html` in a browser. Select Mirror or Front tyre using the buttons or the image. The selection shapes are manually drawn SVG overlays on a single AI-generated raster image; the shapes are not SAM masks and the image is not a layered 3D model. They are for interaction and art-direction evaluation, not mechanical or fitment use.

Generated with the built-in image generation tool on 30 October 2026. Visual references: the GTS 125 UK parts catalogue's PDF page 2 (scope ZAPM31300) for geometry and the existing project photo `public/frieze/photo-gts.jpg` (GTS 300, credited in the project to Michael Wahrlich, CC0) for material/lighting only. The catalogue page itself is not included. Rights and source-review status must be checked before production use; illustration details are not confirmed exact.

Prompt: “Create a very high fidelity photorealistic museum product visualization of the specific Vespa GTS 125 4T Euro 3 UK in reference image 1 (the parts catalogue page), not the different GTS 300 in image 2; use image 2 only as a lighting and materials reference. Closely study reference 1 for the exact silhouette, handlebar and pair of mirrors, round headlight, steering shield, side intakes, single-sided front suspension, wheels, seat, rear body, rack and exhaust. Frame an entire single silver scooter fully in view from the same front-left three-quarter angle as reference 1, horizontal 3:2 landscape composition, with clear space around the mirrors and front wheel. Premium contemporary industrial museum visual: seamless pale neutral grey studio background and floor, soft diffuse natural light, true metal, rubber and glass materials, subtle floor shadow. No text, arrows, labels, inset images, people, or graphic styling. It is a reference visualization and should not be presented as an exact mechanical drawing. The image should be suitable as a base for a later component-isolation prototype.”
