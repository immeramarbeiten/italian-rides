# Licensed model slot

Drop a licensed Vespa GLB here and the `/inspect` page will offer it
automatically (filenames probed: `vespa.glb`, `body.glb`, `wheel.glb`,
`scooter.glb`). Until then the page shows the procedural stylized Vespa
built into `components/vespa-viewer.tsx`.

No Blender CLI is available in this environment, so no GLB has been
exported yet — see the build-step evidence log.
