## Exact scenario

- Fixture: `/fixtures/ai-gts-mirror-cracked-simulated-v2.png`.
- Current UI label: “Mirror · cracked glass”, under AI-generated demo images.
- Concern: **“The mirror glass is cracked. Can it be repaired, or do I need a replacement?”**
- Reference family: GTS; engine: 125. Leave year unknown. It is a synthetic demonstration scenario, not a verified vehicle identification.
- Agent must target **mirror**, not the entire handlebar.
- The owner confirms the assembly. If a side is needed for the reference, make an explicit scenario choice; never infer rider side from image orientation.
- Request asks a workshop to inspect and confirm fitment, without ordering a claimed compatible item.
- Garage outcome: **Planned**.

## Presentation direction

Neutral graphite / light grey desktop backdrop, white browser, small understated window controls, generous margins. Accent colour belongs to the actual mask or selected state. One label per shot, no floating stack of badges. Use the application's actual typography. No text below 28 px in the rendered film; crop the UI where necessary instead of shrinking the whole desktop.

Pointer: normal arrow, dark with white edge, actual pointer movement and actual click rings. Move deliberately. Pause before significant actions. Avoid rapid circles, random zooms and invented clicks. The recording stage includes this pointer automatically.

Audio: warm natural narrator, clear and direct, around 130–145 words/minute. Use silence around the first mask reveal and the request reveal. Music is optional; the demo must work without it. If used, keep it substantially below the voice. No imitation of engine sounds over the real workflow.

## Cut from the main story

Full navigation tour, long timeline exploration, clubs, a generic parts matrix, unsupported repair promises, voice input unless it is proven reliable on the recording machine, model-name roll call in the opening, repeated consent dialogs and repeated confirmations. Keep extended evidence and failure footage as backup clips for judges.

## Release gate

The final needs real screen clips, a checked narration take, captions, one successful uncut agent run, and a proof that the saved record can be refreshed. The storyboard/animatic is not a substitute for those captures. Do not publish a cut whose UI output differs from the narration.
