# Repair scope — what the companion guides vs. explains

Researched Oct 29 from SIP Scootershop tech tips, Haynes Vespa P/PX, Modern Vespa
forums, Scooterotica, and Cantharus/SIP video guides. Rule: guide the DIY jobs,
explain the shop jobs so the owner walks in confident — never DIY-steps for
work that needs a shop.

## DIY six (launch guides)

| # | Repair | Tools needed | Notes |
|---|--------|--------------|-------|
| 1 | Tire + tube (split rim, PX/smallframe) | 13mm socket, tire levers, talc, pump, spare tube | Rims unbolt — no tire machine. Fiddly first time. |
| 2 | Gear oil change (PX/smallframe) | 11mm wrench, drain tray, SAE 30 | One drain + one fill plug, ~250 ml, 15 minutes. |
| 3 | Carb clean / jet swap (Dell'Orto SI/SH) | Screwdrivers, 8–13 mm, carb cleaner, air, gasket kit | Top no-start cause after storage. Screwdriver-level. |
| 4 | Spark plug + HT cap | Plug wrench, gap gauge | 5-minute misfire check. GTS: carry a spare cap. |
| 5 | Control cables (clutch/brake/gears/throttle) | Cable kit, nipples, cutters, lube, wrenches | Tedious routing, not hard. Core carry-spares skill. |
| 6 | Brake shoes + adjustment (drum) | Sockets, brake cleaner, sandpaper | DIY with care: safety-critical, bed in and test. |

## Advanced mode (tool-gated)

| Repair | Gate |
|--------|------|
| Clutch plates (PX Cosa type) | Holding tool (~€20) + circlip pliers + torque wrench |
| CVT belt + rollers + guides (GTS/GT) | Variator/clutch holding tools + torque wrench. Wrong variator-nut torque destroys cranks. |

## Talk-to-your-mechanic mode (explain, don't guide)

| Repair | What the owner should bring |
|--------|-----------------------------|
| Ignition timing / stator faults | Ignition type (points/Ducati), symptoms by RPM, strobe reading if taken |
| Engine rebuild (crank, bearings, seals) | Compression + leak-down numbers, crank play, oil-fouling symptoms, stock-vs-kit wish |
| Fork rebuild / steering bearings / hydraulics | Dive/wobble/sponginess symptoms, mileage since last fork oil |

Shop-talk cheat sheet for all three: model + year + engine code (e.g. VNX2T),
what you already tested, and whether you want OEM or named aftermarket
(SIP/BGM/Malossi) parts.

## Companion features this implies

- Guided diagnostics per DIY job ("won't start" → spark → fuel → carb).
- Spare-parts packing list per job (tube, cables, plug, jets) — the touring feature.
- Mechanic mode: symptom checklist + numbers to bring, explicitly not DIY steps.
